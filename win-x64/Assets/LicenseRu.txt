1. ТЕРМИНЫ
1.1. «ПО» (Программное обеспечение) — приложение Kosofts AI для Windows 10/11,
     включая исполняемые файлы, библиотеки, ресурсы, документацию и обновления.
1.2. «Пользователь» — любое физическое лицо, использующее ПО.
1.3. «ИИ-агент» — функциональность ПО, которая направляет запросы Пользователя
     сторонним поставщикам моделей (далее — «Провайдеры») и возвращает ответы.
1.4. «Поставщик модели (Провайдер)» — третье лицо, предоставляющее доступ к
     языковой модели по API (OpenAI, Anthropic, Google, Groq, Mistral, DeepSeek,
     OpenRouter, Ollama, Azure OpenAI, а также любой иной OpenAI-совместимый сервис).
1.5. «API-ключ» — секретный ключ доступа Пользователя к API Провайдера.

4. СБОР И ОБРАБОТКА ДАННЫХ
4.1. До начала сбора данных ПО выводит отдельный экран выбора с двумя
     вариантами: «Собирать» и «Не собирать». Сбор данных начинается только
     при явном выборе «Собирать» и только после принятия настоящего Соглашения.
     При выборе «Не собирать» этап сбора данных полностью пропускается.
4.2. При наличии согласия ПО может собирать и передавать исключительно
     технические (обезличенные) сведения:
     — версия, сборка и разрядность Windows; признак Windows 10 / Windows 11;
     — производитель, модель устройства, класс устройства, объём памяти,
       количество ядер процессора;
     — разрешение экрана и масштаб DPI;
     — язык, регион и часовой пояс;
     — версия приложения, версия среды выполнения .NET, архитектура процесса;
     — идентификатор установки (случайный GUID);
     — наименование выбранного Провайдера и имя модели;
     — дата/время последнего запуска и последней отправки.
4.3. ПО НЕ собирает и НЕ передаёт: фамилию, имя, отчество, адрес электронной
     почты, номер телефона, адрес, геолокацию, пароли, содержимое файлов,
     историю диалогов с ИИ-агентом, API-ключи Провайдеров, а также любые
     биометрические и специальные категории персональных данных.
4.4. Цели обработки: обеспечение совместимости с Windows 10 и Windows 11,
     диагностика ошибок, подбор поддерживаемых конфигураций, статистика
     использования для заказчика внедрения (Академия ТОР).
4.5. Правовое основание — согласие Пользователя (п. 4.1), которое даётся
     отдельным действием и может быть отозвано в любой момент.
4.6. Хранение и передача: данные передаются по защищённому соединению (HTTPS)
     в базу данных проекта KoSoft Corp (Firebase Realtime Database) и хранятся
     до отзыва согласия либо до достижения целей обработки.
4.7. ОТЗЫВ СОГЛАСИЯ И УДАЛЕНИЕ ДАННЫХ. Пользователь вправе в любой момент:
     — отключить сбор данных переключателем «Отправлять технические данные
       устройства» в разделе «Настройки»;
     — удалить все свои данные кнопкой «Удалить мои данные» в разделе
       «Настройки», после чего узел устройства удаляется из базы данных,
       а локальные настройки и сохранённый API-ключ уничтожаются.
     Если в момент удаления отсутствует подключение к интернету, запрос на
     удаление сохраняется и выполняется автоматически при следующем запуске
     приложения с доступом к сети. Повторное появление данных после удаления
     возможно только при включении сбора данных самим Пользователем.
4.8. Тексты запросов к модели и ответы модели в базу данных Лицензиара

     данных регулируется политикой выбранного Провайдера.
